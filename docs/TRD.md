# PLC 프로그램 초안 도우미 TRD

> **TRD**는 “이 도구를 어떤 부품으로 만들고, 부품끼리 어떻게 이어 붙일지” 정리한 문서예요.

| 항목 | 내용 |
| --- | --- |
| 문서 상태 | 초안 |
| 함께 볼 문서 | [PRD](PRD.md) |
| 현재 만든 것 | 웹 화면과 파일 이름·크기 표시 |
| 아직 없는 것 | AI 에이전트, `.gxw` 읽기, 컴파일, 자동 오류 검사 |

## 1. 만들 때 지킬 점

- 에이전트는 확인된 자료를 바탕으로만 답해요.
- 모르는 내용은 질문하고, 읽지 못한 파일을 읽었다고 하지 않아요.
- 지금 웹 화면은 파일 이름과 크기만 보여줘요.
- 파일을 선택해도 파일 내용은 읽지 않고 인터넷으로 보내지도 않아요.
- 컴파일은 사용자가 GX Works2에서 직접 해요.
- 이 도구가 PLC나 실제 기계를 움직이지 않아요.

## 2. 부품들이 함께 일하는 방법

```text
학생이 도면과 동작 설명을 줘요
              |
              v
에이전트가 읽고, 모르는 점을 물어요
              |
              v
확인한 내용으로 PLC 초안을 제안해요
              |
              v
학생이 GX Works2에서 직접 만들고 컴파일해요
              |
              v
에이전트가 읽을 수 있는 자료만 확인해요
              |
              v
학생과 선생님이 고칠지 결정하고 다시 확인해요
```

지금 웹 화면은 이 과정 중 **파일 선택 화면만** 만들었어요. AI 에이전트와 웹 화면은 아직 연결되지 않았어요.

## 3. 웹 화면은 어떻게 만들어져 있나요?

웹 화면은 설치 없이 브라우저에서 열리는 세 파일로 되어 있어요.

- `index.html`: 화면의 글과 파일 선택 칸을 만들어요.
- `styles.css`: 글자, 색깔, 화면 모양을 정해요.
- `app.js`: 파일 종류를 확인하고 이름과 크기를 보여줘요.

### 선택할 수 있는 파일

- 도면이나 사진: PDF, PNG, JPG
- GX Works2 프로젝트: `.gxw`

파일 선택 창은 해당 종류의 파일을 고르기 쉽게 해줘요. 확장자가 맞아도 파일 내용이 올바른지 알 수 있는 것은 아니에요. 지금 화면은 파일 안쪽을 열어보지 않아요.

## 4. AI 에이전트는 어떤 순서로 일하나요?

1. 학생이 무엇을 만들려는지 확인해요.
2. 도면과 설명을 실제로 읽을 수 있는지 확인해요.
3. 확실히 알 수 있는 내용과 모르는 내용을 나눠요.
4. 입력이나 동작 설명이 부족하면 먼저 질문해요.
5. 확인된 내용만 바탕으로 글로벌 라벨과 PLC 패널 초안을 제안해요.
6. 학생이 GX Works2에서 프로그램을 만들고 컴파일해요.
7. 학생이 읽을 수 있는 프로그램 자료와 컴파일 결과를 주면, 정해진 규칙으로 확인해요.
8. 문제 위치, 이유, 고칠 방법을 알려줘요.
9. 코드를 다시 쓰기 전에는 학생에게 허락을 받아요.

에이전트가 학생의 컴퓨터에서 GX Works2를 눌러 주거나 컴파일하지는 않아요.

## 5. 파일과 답변은 어떤 모양인가요?

### 파일

| 하려는 일 | 학생이 줄 자료 | 지금 화면이 하는 일 |
| --- | --- | --- |
| 도면을 보고 초안 준비 | PDF 또는 사진, 동작 설명 | 파일 이름과 크기만 표시 |
| 프로그램 오류 확인 | GX Works2 프로젝트와 컴파일 결과 | `.gxw` 파일 이름과 크기만 표시 |
| 더 자세한 점검 | PLC 종류·버전, 입출력 이름, 원하는 동작 | 아직 읽거나 분석하지 않음 |

`.gxw`는 여러 자료가 들어 있는 특별한 파일이에요. 파일 안에서 `D/` 같은 글자를 찾더라도, 그 명령이 실제로 어떻게 쓰였는지 알 수 있는 것은 아니에요. 믿을 수 있게 읽는 방법과 시험 자료를 준비하기 전에는 파일을 분석했다고 말하면 안 돼요.

### 답변

문제가 있으면 다음 순서로 알려줘요.

```text
위치: 어디에서 찾았는지
이유: 왜 문제인지
고칠 방법: 어떤 점을 확인하거나 바꿀지
확인 상태: 확인됨 / 더 확인해야 함
```

문제가 없다고 답할 때도 무엇을 살펴봤는지 말해요. 파일을 못 읽었거나 확인할 기준이 없으면 “이상 없음” 대신 “확인 필요”라고 해요.

## 6. 오류를 찾는 규칙은 무엇인가요?

| 살펴볼 것 | 뜻 | 제대로 확인하려면 필요한 것 |
| --- | --- | --- |
| 중복 코일 | 같은 디바이스를 코일로 두 번 이상 사용했어요. | 코일을 나타내는 명령어와 위치를 읽는 방법, 정상·오류 예제 |
| `D/` 순서 | 나눌 대상(S1), 나누는 값(S2), 결과 위치(D) 순서예요. | GX Works2와 Q 시리즈 버전별 명령어 자료, 실제 예제 |
| 비트 크기 | 명령어가 다룰 수 있는 값의 크기와 맞는지 봐요. | 명령어마다 허용되는 크기와 정상·오류 예제 |
| 자기유지·인터록 | 켜짐을 유지하는 회로와 함께 켜지면 안 되는 회로를 봐요. | 기계가 어떻게 동작해야 하는지와 래더 예제 |

규칙이 있다는 것만으로 자동 검사가 되는 것은 아니에요. 컴퓨터가 프로그램 안에서 명령어와 위치를 읽을 수 있어야 해요.

## 7. 자동 검사기를 만들 때 지킬 순서

첫 버전은 원본 파일을 고치지 않고 읽기만 해야 해요.

1. 파일이 정말 지원하는 종류인지 확인해요.
2. 파일을 못 읽거나 버전이 맞지 않으면 오류 결과를 꾸며내지 않아요.
3. 읽은 명령어, 값, 프로그램 안의 위치를 구분해요.
4. 확인된 규칙만 하나씩 적용해요.
5. 어떤 규칙을 어디에 적용했는지 결과와 함께 보여줘요.
6. 읽지 못한 부분이 있으면 전체를 다 검사했다고 말하지 않아요.

현재는 `.gxw`를 읽는 기능을 만들지 않아요. 먼저 GX Works2에서 명령어와 값이 잘 보이게 내보낼 수 있는 파일 종류가 있는지 확인해야 해요.

## 8. 파일 보호와 안전

- 현재 화면에서 선택한 파일은 브라우저 밖으로 보내지 않아요.
- 나중에 에이전트와 연결해 파일을 다른 서비스로 보내게 되면, 어디로 가고 얼마 동안 보관되는지 먼저 알려야 해요.
- 실제 공장 파일보다 가짜 주소를 넣은 연습용 파일을 먼저 써요.
- 이름, 학교 정보, 실제 장비 주소, 비밀 통신 설정은 필요한 경우가 아니면 빼요.
- PLC를 켜거나 끄고, 프로그램을 PLC에 내려보내는 기능은 만들지 않아요.
- 학생이 허락하기 전에는 프로그램을 고치지 않아요.

## 9. 어떻게 시험하나요?

### 웹 화면 시험

- 브라우저에서 페이지가 열리는지 확인해요.
- 도면 선택 칸은 PDF·PNG·JPG를 받고, 프로젝트 칸은 `.gxw`를 받는지 봐요.
- 다른 종류 파일을 고르면 오류 안내가 나오는지 봐요.
- 파일 이름과 크기가 보이고, 지우기 버튼이 동작하는지 확인해요.
- 파일만 골랐는데 검사 결과가 생기지 않는지 확인해요.
- 작은 화면에서도 글자와 버튼이 잘리는지 확인해요.

### 에이전트 시험

- 설명이 충분한 도면과 중요한 내용이 빠진 도면을 각각 줘 봐요.
- 같은 코일을 두 번 쓴 예와 한 번 쓴 예를 비교해요.
- `D/` 순서가 맞는 예와 틀린 예를 비교해요.
- 비트 크기와 자기유지·인터록도 정상·오류 예로 확인해요.
- 읽을 수 없는 파일이나 지원하지 않는 버전에서 “이상 없음”이라고 답하지 않는지 봐요.
- 허락 없이 코드를 고치거나 GX Works2를 조작하지 않는지 확인해요.

아직 자동 검사 기능은 없어서 실제 PLC 프로그램을 정확히 검사하는 시험은 시작할 수 없어요.

## 10. 만들기 순서

1. 어떤 PLC와 GX Works2 버전을 쓸지 정해요.
2. 도면과 라벨 초안의 모양, 명령어를 판단할 자료, 가짜 주소로 만든 예제를 준비해요.
3. 먼저 질문하고 확인한 뒤 답하는 에이전트 안내문을 만들어요.
4. GX Works2에서 읽기 쉽게 내보낼 수 있는 자료 종류를 확인해요.
5. 근거와 예제가 준비된 검사 규칙 하나부터 시험해요.
6. 파일을 어떻게 안전하게 전달할지 정한 뒤 웹 화면과 에이전트를 연결해요.
7. 학생과 선생님이 결과를 살펴보고, 문제가 없을 때만 다음 규칙을 추가해요.

앞 단계가 준비되지 않으면 다음 단계를 끝낸 것으로 보지 않아요.

## 11. 아직 정하지 못한 것

- 에이전트를 어디에서 열고 누가 쓸 수 있을지
- `.gxw`를 안전하고 정확하게 읽을 수 있는지, 다른 파일로 내보낼 수 있는지
- PLC와 GX Works2 버전별 명령어 설명
- 어떤 코일끼리 같은 것으로 볼지
- 숫자와 장치마다 비트 크기를 확인하는 방법
- 자기유지·인터록이 맞는지 판단하는 기준
- 파일을 어디에 저장하고 누가 볼 수 있을지
- 학생과 선생님이 결과를 최종 확인하는 방법

이런 내용이 정해지고 시험을 마치기 전까지는 검사 결과가 완벽하다고 말하면 안 돼요.
