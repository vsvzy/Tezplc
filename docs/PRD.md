# PLC 프로그램 초안 도우미 PRD

> **PRD**는 “어떤 도구를 왜 만들고, 무엇을 할 수 있어야 하는지” 정리한 문서예요.

| 항목 | 내용 |
| --- | --- |
| 문서 상태 | 초안 |
| 만들 도구 | PLC 실습을 돕는 Copilot Studio 에이전트 |
| 참고 자료 | 사용자가 준 에이전트 기획서 |
| 사용할 프로그램과 PLC | GX Works2, Mitsubishi Q 시리즈 |

## 1. 어떤 도구인가요?

PLC는 기계가 어떤 순서로 움직일지 알려주는 장치예요. 이 도구는 PLC를 배우는 사람이 도면과 동작 순서를 바탕으로 프로그램 초안을 준비하도록 도와주는 AI 에이전트예요.

먼저 도면과 설명을 읽고, 모르는 점이 있으면 질문해요. 답을 확인한 다음 글로벌 라벨과 PLC 패널의 초안을 제안해요. 사용자가 GX Works2에서 직접 만든 프로그램을 보여 주면, 정해진 기준으로 확인하는 것이 목표예요.

이 도구가 기계를 직접 움직이지는 않아요. 프로그램이 안전하고 틀림없다고 보증하지도 않아요. 실제 프로그램은 학생과 선생님이 GX Works2에서 확인해야 해요.

## 2. 왜 만드나요?

프로그램을 쓰기 전에 기계가 움직일 순서를 정리하지 않으면, GX Works2에서 어디서부터 시작할지 막힐 수 있어요. 코일이나 명령어를 잘못 쓰거나 자기유지·인터록 회로를 빠뜨릴 수도 있어요.

이 도구는 순서를 먼저 정리하고, 확인된 내용만으로 초안을 준비하게 도와줘요. 프로그램에서 문제가 보이면 위치와 이유를 쉬운 말로 설명해요.

### 잘 만들었다고 볼 수 있는 모습

- 도면 확인 → 초안 만들기 → 프로그램 확인 순서가 잘 지켜져요.
- 모르는 내용은 마음대로 정하지 않고 사용자에게 물어요.
- 문제를 찾으면 위치와 이유, 고칠 방법을 알려줘요.
- 확인하지 못한 부분은 “확인 필요”라고 말해요.
- 확인한 범위에 문제가 없을 때만 “확인한 범위에서 이상 없음”이라고 말해요.
- 사용자가 허락하기 전에 코드를 다시 쓰거나 동작을 바꾸지 않아요.

## 3. 누가, 언제 쓰나요?

PLC와 GX Works2를 배우는 학생이 실습할 때 사용해요. 사용자는 도면과 “기계가 어떻게 움직여야 하는지” 설명을 먼저 보여줘요. 에이전트가 질문하고 초안을 제안하면, 학생이 GX Works2에 직접 옮겨 컴파일하고 동작을 확인해요. 컴파일은 프로그램에 잘못된 곳이 있는지 GX Works2가 검사하는 과정이에요.

## 4. 이 도구가 할 일과 하지 않을 일

### 첫 번째 버전에서 할 일

- 도면이나 사진과 동작 설명을 읽어요.
- 입력·출력, 움직이는 순서와 조건을 정리해요.
- 설명이 빠졌거나 서로 맞지 않으면 먼저 질문해요.
- 확인한 내용만 바탕으로 글로벌 라벨과 PLC 패널의 초안을 제안해요.
- 합의한 기준에 따라 다음 항목을 확인하도록 만들어요.
  - **중복 코일:** 같은 디바이스(PLC 안에서 입력이나 출력을 가리키는 이름)를 코일로 두 번 이상 쓴 경우
  - **비트 크기:** 명령어가 다룰 수 있는 값의 크기와 실제 값의 크기가 맞지 않는 경우
  - **자기유지·인터록:** 계속 켜져 있어야 하는 동작이나, 함께 켜지면 안 되는 동작의 회로
  - **D/ 나눗셈 명령어:** `D/ 나눌 대상(S1) 나누는 값(S2) 결과 위치(D)` 순서인지 확인
- 문제가 보이면 “위치 → 이유 → 고칠 방법” 순서로 설명해요.
- 코드를 고치기 전에는 사용자에게 먼저 물어요.

### 첫 번째 버전에서 하지 않을 일

- GX Works2를 대신 눌러 주거나 컴파일하지 않아요.
- `.gxw` 파일 안의 래더 프로그램을 읽어 자동 검사하지 않아요. 이 파일의 저장 방법과 읽는 규칙이 아직 확인되지 않았어요.
- 허락 없이 코드를 고치거나 GX Works2 프로젝트를 덮어쓰지 않아요.
- PLC나 실제 기계에 연결하거나 작동 명령을 보내지 않아요.
- 안전 인증서처럼 프로그램이 완전히 안전하다고 보증하지 않아요.
- 규칙이 정해지지 않은 비트 크기 문제를 임의로 판정하지 않아요.

현재 웹 화면은 PDF·사진과 `.gxw`를 선택하고 이름과 크기를 보여줘요. **파일을 선택하는 것만으로는 도면을 읽거나 오류를 찾지 않아요.**

## 5. 필요한 기능

### 도면 읽기

도면과 설명에서 확인한 내용, 잘 모르겠는 내용, 사용자에게 물어볼 내용을 나누어 보여줘요. 그림에 없는 배선이나 움직임은 만들어 내지 않아요.

### PLC 초안 만들기

사용자가 확인해 준 도면과 동작 설명을 바탕으로 글로벌 라벨과 PLC 패널 초안을 제안해요. 중요한 정보가 빠졌으면 추측하지 않고 질문해요.

### 프로그램 확인

학생이 GX Works2에서 만든 프로그램과 컴파일 결과 중 실제로 읽을 수 있는 자료만 확인해요. 점검할 수 없는 부분이 있으면 그 사실을 먼저 알려요. 오류를 발견해도 학생이 허락하기 전에는 코드를 바꾸지 않아요.

### 쉬운 답변

짧은 존댓말을 써요. 각 문제에는 위치, 이유, 고칠 방법을 적어요. 자료가 부족하거나 읽히지 않으면 “확인 필요”라고 말해요.

## 6. 다 만들었는지 어떻게 확인하나요?

- [ ] 도면과 동작 설명을 먼저 확인하고, 필요한 질문을 해요.
- [ ] 학생이 확인해 준 내용만으로 초안을 만들어요.
- [ ] 중복 코일, 명령어 크기, 자기유지·인터록, `D/` 순서의 시험 예제로 확인해요.
- [ ] 문제가 있으면 위치·이유·고칠 방법을 보여줘요.
- [ ] 정상, 오류, 정보 부족, 파일을 읽지 못한 경우를 서로 다르게 알려줘요.
- [ ] GX Works2에서 직접 확인하는 순서와 사람이 확인할 부분을 안내해요.
- [ ] 사용자가 허락하기 전에는 코드를 다시 쓰지 않아요.

시험에는 정상 예와 오류 예를 모두 준비해야 해요. 자동 검사가 준비되기 전까지는 이 목록을 “이미 할 수 있는 기능”으로 설명하면 안 돼요.

## 7. 안전과 파일 보호

- 실제 설비 파일보다 가짜 주소를 넣은 연습용 복사본을 먼저 사용해요.
- 실제 파일을 공유하려면 파일 주인이나 학교의 허락을 먼저 받아요.
- 학교 이름, 사람 이름, 실제 장비 주소, 주석, 통신 설정처럼 필요하지 않은 정보는 빼요.
- 파일이 다른 서비스로 전달되거나 저장된다면, 어디에 왜 저장되는지 사용자에게 알려요.
- 에이전트의 답은 학생이 GX Works2에서 직접 확인하거나 선생님이 검토하는 일을 대신하지 않아요.
- PLC에 직접 연결하거나 기계를 움직이는 기능은 만들지 않아요.

## 8. 나중에 정해야 할 것

- 에이전트를 어디에서 쓸지, 누가 사용할 수 있을지
- GX Works2가 `.gxw`를 저장하는 방법과 프로그램을 읽을 수 있는 자료 형식
- PLC 종류와 GX Works2 버전별 명령어 설명
- 어떤 명령을 코일로 셀지, 중복으로 볼 범위
- 명령어마다 올바른 비트 크기를 판단하는 규칙
- 자기유지·인터록이 맞는지 판단할 동작 설명과 시험 예
- 도면에서 만들 글로벌 라벨과 패널 초안의 모양
- 파일을 얼마나 오래 보관하고 누가 볼 수 있는지
- 학생과 선생님이 결과를 확인하는 방법

이 내용을 정하기 전에는 자동 검사가 완벽하다거나 기계가 안전하다고 말하면 안 돼요.
